# 一人生意独立数据源

这是“生意雷达”的编辑数据层。外部 RSS、网页和社区讨论只作为候选输入，公开站点只发布经过我们筛选、归组和摘要的数据。

编辑流水线：`raw`（原始候选）→ `reviewed`（核验过的事实）→ `published`（公开展示）。每条记录保留原文链接、来源、时间、证据等级和编辑备注；理论上可行但尚未验证的机会允许进入 `discussion`，但必须明确写成“有人讨论/推断”，不得写成收入承诺。

重点覆盖独立开发、数字产品、自由职业、服务生意、电商与内容变现，以及获客、定价、现金流、平台规则和政策变化。目标不是收集所有创业新闻，而是持续回答：一个普通人能否做、为谁做、如何获客、要付出什么成本、证据有多强。

原文全文不复制到公开数据层；默认公开中文摘要和原文链接。该目录不放密钥、抓取缓存或个人信息。
